# Kurdish Kurmanji Keyboard
A native and seamless keyboard layout engineered specifically for Kurmanji Kurdish speakers on Linux environments.

## Quick Installation

Install and activate the keyboard instantly using a single command in your terminal:

```bash
git clone https://github.com/Zinaro/KurdishKurmanjiKeyboard.git && cd KurdishKurmanjiKeyboard && chmod +x install.sh && ./install.sh && setxkbmap ku
```
